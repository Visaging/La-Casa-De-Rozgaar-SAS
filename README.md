## Overview

**La Casa De Rozgaar (LCDR)** is an evidence-based, AI/ML-driven Workforce Intelligence and Decision Support Platform built for the SAS Hackathon. The platform transforms raw labor market records and psychometric/skill assessments into actionable, interactive intelligence for candidates, employers, and workforce planners.

### Core Workflow Principle

$$\text{Competition Datasets} \longrightarrow \text{Data Engineering} \longrightarrow \text{Market \& Skill Analytics} \longrightarrow \text{Predictive ML} \longrightarrow \text{What-If Simulation} \longrightarrow \text{LCDR UI}$$

The platform operates across two unified personas:
- **Candidate Intelligence (Heist Mode):** Real-world skill benchmarks, gap identification, AI job compatibility, and dynamic What-If career simulation.
- **Employer Intelligence (Professional Mode):** Macro-market hiring trends, talent capability mapping, workforce gap analysis, and compensation intelligence.

---

## Competition Datasets & Ground Truth

The analytics engine is grounded strictly in the 4 official competition datasets:

1. **Data Science Jobs** (1,602 postings, 642 companies, 10 core DS roles, 93,000+ openings represented)
2. **Analytics Jobs** (15,841 postings, 79,880 skill tokens, 8 major geographic hubs, structured salary brackets)
3. **JDS Skill Traits** (139 Junior Data Scientists; 5 skill dimensions $\rightarrow$ `salary_hike_high_or_low` classification)
4. **SDS Personality Traits** (161 Senior Data Scientists; Big Five OCEAN dimensions $\rightarrow$ `success_classification`)

---

## Data Provenance Standards

Every number, chart, and KPI displayed across the application carries strict provenance:
- `REAL DATA`: Mathematically computed directly from audited dataset records.
- `MODEL OUTPUT`: Generated by validated statistical / ML models (Logistic Regression, Random Forest).
- `SIMULATION`: Dynamic What-If calculations reflecting hypothetical candidate / workforce skill adjustments.
- `DEMO / PROTOTYPE`: Restricted to non-dataset sandbox features.

## Tech Stack & Architecture

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion + Recharts + Lucide Icons
- **Analytics & ML:** Python 3.12, Pandas, Scikit-learn, OpenPyXL, SQLite
- **Backend API:** Express.js / Node.js + TypeScript (Dual SQLite / Cloud PostgreSQL sync)
